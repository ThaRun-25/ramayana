THE EPIC ATLAS — INTERACTIVE RAMAYANA MAP

HOW TO RUN
1. Extract the ZIP file.
2. Open the movie-map-website folder in VS Code.
3. Start index.html with Live Server (recommended), or open index.html in a modern browser.

INTERACTIONS
- Scroll up/down to move through Ayodhya, Mithila, Kishkindha, and Lanka.
- The four landmark structures remain on the map; the current location is gently highlighted.
- Click a landmark directly to jump to that location.
- Use the top-left menu or arrow keys as alternate navigation.
- Click DISCOVER THIS LAND for a short location note.
- Toggle MOTION ON/OFF to disable the animation and cursor sparkle effects.
- A one-second Ramayana title card plays on every page load/reload.
- A custom gold mythical cursor and restrained sparkle trail appear inside the website.

FILES
- index.html: page structure
- style.css: cinematic layout, landmark highlighting, cursor and animations
- script.js: scroll/keyboard/touch navigation and location content
- assets/: landscape, title card, and four location illustrations

NOTES
- This is a static website. It does not require a backend or database.
- The custom cursor and visual effects work best in desktop browsers; touch devices use swipe navigation.
